About Two-Level Paging & TLB Simulator

          
        

        

          
Virtual Memory Concepts

          

            In modern operating systems, physical memory (RAM) is split into fixed-size chunks called
            Frames, and virtual address space is divided into same-sized chunks called
            Pages.
          

          

            

              
1. Address Decomposition

              

                A 32-bit virtual address is partitioned into:
                
• Page Directory Index (10 bits)
                
• Page Table Index (10 bits)
                
• Offset (12 bits) = 4,096 bytes per page
              

            

            

              
2. Translation Lookaside Buffer (TLB)

              

                A high-speed cache located on the CPU MMU that maps VPN directly to PFN. A TLB Hit
                resolves an address in 10 ns without walking multi-level page tables in main memory.
              

            

            

              
3. Demand Paging & FIFO Eviction

              

                When a page is accessed that is not currently resident in physical frames, a Page Fault
                occurs. The OS allocates a free frame or evicts the oldest frame using First-In First-Out
                  (FIFO).
              

            

            

              
4. Effective Access Time (EAT)

              

                Calculated dynamically based on lookup times:
                
• TLB Hit: TLB (10 ns) + Data Access (100 ns) = 110 ns
                
• TLB Miss (Page in RAM): TLB (10 ns) + 2 Page Walks (200 ns) + Data (100 ns) = 310 ns
                
• Page Fault: 310 ns + Page Fault Service Time (8,000,000 ns)
